# Hermes Voice Note

Голосовые вложения прямо в Hermes Desktop: **«🎙 Записать» → «Отправить»**, рядом **«Отмена»**. Без отдельного рекордера, предварительного распознавания и собственного backend. Во время записи видна красная точка и таймер; переходы плавные и учитывают системное уменьшение движения.

## Установка

Нужен **Hermes Desktop** с публичными SDK API `focusedSessionOwner`, `profileRoutes`, `retainProfile`, `requestProfile` и `composer.submit`. Плагин устанавливается на машину с Desktop, даже если backend удалённый.

1. Открой **Capabilities → Plugins → Install from Git**.
2. Укажи `https://github.com/renidere/hermes-voice-note`.
3. Выбери Desktop, подтверди установку и включи плагин.

На Windows можно открыть [`install/Install.url`](install/Install.url). Он запускает тот же диалог с явным подтверждением, а не устанавливает код молча.

### Обновление установленной версии

Сначала **отправь или отмени текущую запись**: обновление выгружает старый экземпляр плагина и освобождает микрофон, несохранённая запись будет потеряна.

Повтори установку из публичного URL с опцией **Force reinstall**. Для Windows подготовлен [`install/Update.url`](install/Update.url): он заранее отмечает переустановку в штатном диалоге, но всё равно требует подтверждения. Обновляется тот же `hermes-voice-note`, второй плагин с таким же ID не нужен. Рабочий backend перезапускать не требуется.

Установщик получает текущую ветку репозитория и проверенный им commit. Автоматического обновления в фоне плагин не делает. Теги GitHub Releases сохраняют конкретные выпуски, но URL вида `tree/<tag>` **не является способом закрепить версию в текущем установщике**.

## Использование

- Открой **существующий** чат, нажми «🎙 Записать» и при необходимости разреши микрофон.
- Красная точка означает активную запись. Разрешение микрофона и загрузка файла имеют отдельные статусы; красная точка в эти моменты не показывается.
- «Отправить» останавливает захват и отправляет **сам WAV**, не ожидая ASR.
- Исходный чат и его маршрут фиксируются до асинхронного захвата. Переключение фокуса не меняет получателя. Если исходный composer уже не виден, вернись в исходный чат и повтори отправку.
- Несвязанный текстовый черновик и другие вложения не отправляются и не стираются плагином.
- При ошибке отправки WAV остаётся в памяти для повтора. «Отмена» освобождает микрофон и отменяет последующую отправку сообщения.
- При включённом `prefers-reduced-motion` анимация отключается, красная точка и текстовые статусы остаются.

## Приватность

- Нет телеметрии, сторонних речевых API, загрузки моделей или ASR/LLM-вызовов внутри плагина.
- Аудио идёт в **настроенный пользователем Hermes backend** штатным `file.attach`. После отправки начинается обычный ход чата, который может обратиться к выбранному пользователем модельному провайдеру. Это не обещание полностью локальной обработки всей переписки.
- Неотправленная запись находится в памяти Desktop, не в дисковой библиотеке. Закрытие приложения, отключение и обновление плагина могут её потерять.
- Отмена во время уже начавшегося upload не отзывает байты с сервера: файл может остаться среди backend-вложений, хотя сообщение в чат не отправлено.
- В репозиторий и релизы не входят пользовательские записи, локальные отчёты, ключи, адреса частной инфраструктуры и старая внутренняя Git-история.

## Формат и ограничения

- PCM16 WAV, до двух каналов; без собственного усиления, фильтров и сведения каналов. Реальное число каналов зависит от устройства и браузера.
- `echoCancellation`, `noiseSuppression`, `autoGainControl` запрашиваются выключенными. Если трек явно сообщает включённую обработку, захват отклоняется. Отсутствующие настройки не доказывают отсутствие DSP; аппаратную обработку плагин не контролирует.
- Частота WAV соответствует `AudioContext`; браузер может ресемплировать вход. Float32 → PCM16 квантует сигнал: это не bit-exact захват АЦП.
- До **5 минут или 64 MiB PCM**. На лимите захват прекращается; отправка остаётся явным действием пользователя.
- Первый аудиопост в совершенно пустой новой сессии пока не поддержан: нужна существующая сессия для upload.
- Используется поддерживаемый нынешним клиентом, но устаревающий `ScriptProcessorNode`; будущая замена на AudioWorklet потребует отдельной проверки.

## Разработка и проверки

Runtime — один `plugin.js`, без сборки и установки npm-пакетов. `private: true` в `package.json` предотвращает случайную публикацию в npm и не относится к публичности GitHub.

Для тестов используются Node, `jsdom`, React и ReactDOM как devDependencies; runtime по-прежнему использует React, предоставленный Hermes.

```sh
npm ci
npm test
npm run test:dom
```

Тесты исполняют настоящий модуль с fixture SDK и аудиограницами. DOM-регрессия проверяет настоящие `button.click()` внутри формы: Record/Send/Cancel не должны отправлять несвязанный черновик. Это не эмуляция всей оболочки Hermes.

Дополнительный Linux smoke требует установленный Chromium/Chrome и `/usr/bin/ffmpeg`, `/usr/bin/ffprobe`:

```sh
npm run test:browser
```

Он использует синтетический микрофон, локальный fixture receiver и не вызывает модель. Создаваемые аудио/логи сохраняются в игнорируемом `evidence/` и не публикуются. Границы опубликованных проверок описаны в [VALIDATION.md](VALIDATION.md).

Дополнительная проверка UI с настоящим SDK Button требует checkout Hermes с установленными frontend-зависимостями (`esbuild`, React/ReactDOM) и Chrome:

```sh
HERMES_SOURCE_ROOT=/path/to/hermes-agent npm run test:ui-browser
```

Этот opt-in smoke проверяет normal/reduced motion, динамическую смену настройки, стабильность DOM и изоляцию CSS. Его оболочка/тема и host остаются fixtures; он не заменяет нативный Desktop E2E. Неиспользуемая ветка иконки загрузки SDK Button в harness заглушена.

## Удаление

Отключи/удали «Голосовые сообщения» в Plugins. Микрофон будет освобождён, уже отправленные backend-вложения останутся.

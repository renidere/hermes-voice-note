# Безопасность и приватность

Плагин получает микрофон только после явного нажатия записи и передаёт аудио в выбранный Hermes backend только по действию отправки. Наличие подключённого облачного провайдера не вызывает отдельный ASR автоматически; обычная обработка сообщения самим Hermes от плагина не зависит.

Не прикладывайте реальные аудио, ключи, токены, приватные backend-URL и диагностические конфигурации к публичным issues. Для воспроизведения используйте синтетические данные. Уязвимости лучше отправлять через приватный канал владельцу репозитория, а не публиковать эксплуатационные детали вместе с секретами.

Отмена не удаляет уже загруженный файл с backend. Выгрузка/обновление плагина не сохраняет незавершённый WAV на диск. Статическая проверка исходников и отсутствие секретов в публикуемом дереве не заменяют контроль доступа к вашему Hermes и безопасность микрофона/ОС.

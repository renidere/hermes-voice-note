# Границы проверок выпуска 0.3.0

## Воспроизводимые проверки

- `npm ci --ignore-scripts`: установка только devDependencies для тестов; runtime не требует npm install.
- `npm test`: тесты настоящего ESM-модуля через fixture SDK/audio boundary, включая запись/отмену, адресность, ошибки upload и представление состояний UI.
- `npm run test:dom`: реальные нативные нажатия кнопок внутри родительской формы в jsdom; проверка нулевых посторонних submit и сохранности черновика.
- `npm run test:browser`: настоящий Linux Chromium с синтетическим микрофоном → WebAudio → PCM WAV → локальный fixture receiver. Полное декодирование FFmpeg и проверка структуры WAV.
- Тесты входного сигнала проверяют RMS отдельных каналов, тишину, ограничение публикации 10 Hz и сброс при остановке/отмене. UI-регрессия подаёт PCM в настоящий callback и проверяет изменение мини-индикатора без перерисовки всей панели.
- Дополнительные UI-тесты проверяют индикатор записи, компактность в CSS px, стили переходов и reduced motion; конкретный способ и ограничения видны в исходниках тестов.

Для выпуска использованы локальные Node v26.7.0 и jsdom 29.1.1. Это не заявление о прохождении GitHub Actions: облачный CI не настраивался и не запускался.

## Что не следует выводить из этих проверок

- Fixture SDK не заменяет весь Electron/Windows-клиент. Новый интерфейс нужно проверить после установки обновления на целевом клиенте.
- На непубличном прототипе 0.1.0 отдельно был получен настоящий микрофонный WAV через Desktop и проверен на backend. Исходное аудио и персональные отчёты не публикуются. Это не объявляется новым native E2E для UI версии 0.3.0.
- Отдельная изолированная проверка настоящего gateway для прототипа подтверждала subscription/resume/upload/staging; её персональное окружение и receipts не входят в публичный пакет. Публикуемый browser smoke использует fixture receiver, а не настоящий gateway.
- Нет измеренной гарантии отсутствия аппаратного DSP, ресемплинга браузера или аналогового клиппинга. По PCM WAV нельзя восстановить все настройки микрофона/драйвера.
- Не проверены все варианты сетевого сбоя, выключения ОС и смены чатов на живом Windows-клиенте.
- Нет оценки дикции/интонации и вызовов речевых моделей внутри плагина.

## Публичный состав

Публикуется только выбранное текстовое дерево проекта с новой историей Git. Пользовательские записи, `evidence/`, ключи, конфигурация личного окружения, установленные devDependencies и внутренние адреса не включаются. Коммиты используют публичный GitHub noreply-адрес владельца. Тестовые WAV создаются самим тестом из синтетического сигнала и не являются пользовательскими записями.
